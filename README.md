# Employee Asset Management System

A responsive employee asset management web application built with React, TypeScript and Vite.

## Features
- Dashboard with asset statistics
- Assigned Assets management
- Asset Request form
- Asset Return Status tracking
- Search/filter assets
- Form validation
- Responsive desktop, tablet and mobile UI
- Clean professional interface

## Tech Stack
React.js • TypeScript • Vite • CSS • Lucide React

## Run Locally
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Project Structure
```text
src/
├── App.tsx
├── main.tsx
└── styles.css
```

## Purpose
This project demonstrates frontend development skills including React components, TypeScript state management, form handling, validation, responsive CSS and reusable UI patterns.
